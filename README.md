# FreePromptLibraryAI starter
Responsive English/Hindi prompt library with 50 starter photo and video prompts, search, categories, detail view and copy button.

## Files
- index.html — homepage
- styles.css — responsive styling
- app.js — search, filters and copy interaction
- prompts.js — 50 prompt records

## Deployment
Static frontend starter. Backend features are not connected yet: admin authentication, database, image uploads and scheduled trend research. Add those before treating the site as complete or AdSense-ready.
