નવી અપડેટ — Homepage Builder અને Page Navigation

1. Homepage Builder ના Hero, Search, Navigation, Footer અને Contact/Social વિભાગો હવે અલગ Edit cards દ્વારા modal માં ખુલશે.
2. દરેક વિભાગના ફેરફારો માટે modal ની અંદર અલગ Save this section બટન છે. જૂનું બહાર દેખાતું Save homepage controls બટન દૂર કરાયું છે.
3. Information Pages ના About, Contact, Privacy Policy, Terms & Conditions, Disclaimer અને DMCA cards ક્લિક કરતાં અલગ editor modal ખૂલે છે. જૂનું નીચેનું inline editor દૂર કરાયું છે.
4. Policy text linkify કરતી વખતે થતી JavaScript regular-expression ભૂલ સુધારાઈ છે.
5. Homepage પરથી માહિતી પેજ પર જઈ પાછા આવતાં homepage નું અગાઉનું scroll સ્થાન restore કરવાનો પ્રયાસ ઉમેર્યો છે.
6. Footer/Disclaimer markup અને Supabase schema/records બદલ્યા નથી.

Deploy:
- ZIP extract કરો અને GitHub main branch માં files upload/replace કરો.
- Supabase માં કોઈ SQL ફરીથી ચલાવવાની જરૂર નથી.
- Deploy થયા પછી Homepage Builder ના દરેક Edit modal અને Save test કરો.
