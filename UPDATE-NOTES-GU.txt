FreePromptLibraryAI – Edit Button + Admin Session Fix

આ અપડેટમાં:
1. Homepage Builder initialization દરમિયાન Follow Us card ખસેડતી વખતે થતી JavaScript scope error સુધારી છે. આ error ના કારણે Edit click handlers સુધી કોડ પહોંચતો નહોતો.
2. Homepage Builder ના દરેક Edit button માટે dialog launch handlers હવે initialize થઈ શકે છે. Dialog હાલ full-screen editor તરીકે દેખાય છે.
3. Supabase Auth માં persistSession અને autoRefreshToken સ્પષ્ટ રીતે ચાલુ રાખ્યા છે જેથી refresh પછી login session જળવાય.
4. 30 મિનિટ inactivity નો સમય localStorage માં જળવાય છે; refresh કરવાથી inactivity timer ફરીથી શૂન્ય થતો નથી.

Deploy કર્યા પછી hard refresh (Ctrl+Shift+R) કરો. Edit buttons અને Save ને Supabase સાથે live test કરવાનું બાકી છે; પહેલાં એક વિભાગમાં ફેરફાર કરી Save ચકાસો.
