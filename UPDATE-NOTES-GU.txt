Update notes - page loading and homepage builder card layout

1. Fixed the policy-term link conversion in page.js. The previous dynamically-created regular expression could throw a JavaScript syntax error while rendering saved page content. It now safely links Terms & Conditions, Privacy Policy and Disclaimer.
2. Information page database errors are logged and shown as a useful message instead of silently being presented as a missing page.
3. Homepage Builder settings groups (Header text, Search controls, Navigation, Footer, Contact/Social) are now displayed as separate full-width edit cards with independent Edit/Close controls.
4. Information page shortcuts are displayed as separate full-width edit rows.

No database migration or destructive SQL is included in this patch. Existing Supabase data, prompt records, and uploaded images are not changed by these frontend changes.
